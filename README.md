# Núcleo Espírita Lar de Maria – página de entrada

Página pública de entrada do sistema da casa: mostra o logo e o nome, explica que o acesso é pela conta do Claude, com o e-mail cadastrado pela coordenação, e leva para a página da casa no Claude.

Não há dado de pessoa aqui. A página é gerada no repositório do sistema (`npm run entrada`, a partir de `publicar/entradas.json`): o arquivo `dist/entrada/lm/index.html` vira o `index.html` deste repositório, junto com o manifesto e os ícones da tela inicial.
